Bind a map
The image this effect reads. Only a reference is kept — the map never reaches the canvas, the mask or the sampled output.
Bind a Direction
Point this light with a Direction attribute from anywhere in the project — the arrow is read as the direction the light travels, so the light sits behind it and the shadow falls ahead. While bound the manual Angle/Elev knobs are hidden; only the reference is kept.
Font
Each name is drawn in its own face, so what you see here is what the layer gets. A face this machine does not have is dimmed and draws in the stack's fallback.
